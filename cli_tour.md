


# CLI Tour

- **Getting help:** `/help`
- **Switching modes:** `Tab` / `Shift+Tab`
- **Browsing available models:** `/models`
- **Custom agents overview:** `/agents`
- **Fleet of background agents:** `/fleet`
- **Monitoring running work:** `/tasks`
- **Yolo mode for automatic task execution:** `/yolo`
- **Perform a Security Review:** `/security-review`
- **Perform a token optimization check on history/tools:** `/chronicle`
- **Ask a side question without adding to conversation history:** `/ask`
- **Run Shell Commands:** `!make install` or `make dev`
